# Hrithika D — Artist Portfolio · Version 2

Version 2 is a more curated, gallery-oriented presentation of the current artwork collection.

## What changed
- Stronger editorial homepage and hero section
- Collection cards for Portraits & Figures, Cultural & Devotional, and Landscapes & Places
- More sophisticated 12-column artwork gallery
- Filterable artwork categories
- Full-screen artwork lightbox with keyboard navigation
- Clear artwork metadata without inventing year/size
- Sharper artist statement and About section
- Practice/medium list
- Commission process: idea → confirmation → creation & delivery
- Availability strip
- Contact form that prepares an email
- Mobile navigation and responsive layouts
- Accessibility improvements and semantic structure

## Before publishing
1. Replace `your-email@example.com` in `index.html` and `script.js`.
2. Replace `https://instagram.com/` with the real Instagram profile.
3. Replace artwork crops with original high-resolution photographs/scans.
4. Confirm each artwork title and medium.
5. Add actual dimensions, year, availability and price only when you have those details.
6. If selling originals, add a separate Shop / Available Works section rather than mixing sales information into the gallery.
